# Criolaser · Temporada de verão

Prévia comercial da Criolaser para avaliação. A apresentação online não confirma contratação ou aprovação comercial das condições da temporada.

## Executar

`npm ci`, `npm run dev`. Desenvolvimento: http://localhost:3019/ . `npm run check` verifica TypeScript; `npm run build` produz dist local. O GitHub Actions gera o pacote Pages com a base `/criolaser-estetica-criciuma/` após push na `main`.

React + TypeScript + Vite. CSS autoral com tokens em src/styles.css, conteúdo em src/content.ts. Ícones Phosphor. Sem bibliotecas de animação pesadas; movimento curto em CSS, dialog nativo para o menu. Figtree autohospedada (SIL OFL via Fontsource). Derivados WebP publicados em `public/assets`. Originais de trabalho permanecem locais, fora do repositório público. `node scripts/prepare-assets.mjs` reproduz recortes e otimização usando esses originais.
